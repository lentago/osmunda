# flux-system (placeholder — EKS overlay)

Populated by `flux bootstrap` when the ephemeral EKS cluster is stood up (see
[`runbooks/eks-up.md`](../../../runbooks/eks-up.md)). Because the cluster is
torn down after use, this is bootstrapped fresh each time rather than kept as a
standing checkout. See [`../README.md`](../README.md) for the cost gate.
